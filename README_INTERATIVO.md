# Alfabetizando TEA — versão interativa

Esta versão adiciona uma nova camada de jogos reais ao site:

- Associação imagem-palavra
- Jogo da memória
- Caça-palavras em grade
- Monte a palavra por partes
- Sequências lógicas
- Desafio matemático
- Níveis Inicial, Intermediário e Avançado
- Leitura por voz
- Feedback imediato
- Layout responsivo
- Mantém referência às 25 categorias e às 5.000 atividades-base
