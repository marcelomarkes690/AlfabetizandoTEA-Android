# Alfabetizando TEA — versão completa

Versão web responsiva para GitHub Pages.

## Conteúdo
- 5.000 atividades geradas de forma determinística
- 25 categorias
- 200 atividades por categoria
- Alfabetização, hipóteses de escrita, leitura, interpretação, ortografia, vocabulário, frases, caça-palavras
- Memória, atenção e sequências
- Matemática: números, adição, subtração, multiplicação, divisão, geometria, medidas, tempo, dinheiro e gráficos
- Níveis Inicial, Intermediário e Avançado
- Leitura por voz
- Progresso salvo no navegador
- Layout responsivo

## Como atualizar no GitHub
Substitua os arquivos `index.html`, `style.css` e `script.js` da raiz do repositório.
